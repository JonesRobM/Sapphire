# Examples

Copy one of these next to your data, edit the `System` / `Quantities`
dictionaries, and run it with `python`.

| Script | Purpose |
|---|---|
| `run_analysis.py` | Drive `Sapphire.Process` over an MD trajectory and pickle the resulting metadata. |
| `plot_results.py` | Read one or more `Metadata.csv` pickles and produce the standard figure set. |

Supported quantity keys are listed in `Sapphire/Utilities/Supported.py`.
