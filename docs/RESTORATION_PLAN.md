# Sapphire Restoration Plan

_Drafted 2026-08-28. Status legend: ☐ todo · ◐ in progress · ☑ done · ✋ needs Rob (git / decision)._

Sapphire is the post-processing environment for metallic-nanoparticle MD written
during Rob Jones's PhD (Baletto group, KCL). Goal of this plan: make it install,
import and run cleanly on modern Python again, shrink the repository, and leave
it in a state where further science can be added with confidence.

Ground rules for the work:

* **No git commands are run by Claude.** Every phase ends with a list of files
  changed and the exact git commands for Rob to run.
* Behaviour-preserving first. Phases 1–3 change *no* numerical results; they
  only fix imports, packaging and tree hygiene. Bug fixes that could change
  output are isolated in Phase 4 and each one is noted.
* Nothing scientific is deleted. Stagnant code is moved to `legacy/`, not
  removed, so it can be resurrected when its purpose is remembered.

## Phase 5 — Shrink history (721 MB `.git`)  ◐ helper + samples + runbook done; ✋ Rob runs `docs/HISTORY_REWRITE.md`

Root cause: `main/Sapphire/Tutorials/Data/{AgNi,AuPd,AuPt,CuNi}.tar.gz`
(4 × 58 MB; each holds two ASE `.traj` binaries of ~48 MB) plus historic
`.egg`/`build/` churn.

Data strategy (decided 2026-08-28):
1. **Cannot be regenerated deterministically** — they are stochastic 14 ns MD
   runs. Keep the originals, but *outside* git history.
2. Host the four tarballs as a **GitHub Release asset** (`data-v1`) — free, no
   LFS quota. `Sapphire.Tutorials.data.fetch("AuPt")` downloads + caches to
   `~/.cache/sapphire/` with a SHA-256 check.
3. Ship a **down-sampled sample** in-repo: every 20th frame of one simulation
   per system, written as compressed extxyz (~1–2 MB each) so tutorials run
   offline.
4. Offer `Sapphire.Tutorials.data.synthetic(...)` — ASE + EMT/Gupta short MD on
   a small cluster, seeded, for smoke tests that need a "trajectory-shaped"
   input without any download.
5. History rewrite with `git filter-repo` on a fresh clone; commands will be
   listed verbatim in `docs/HISTORY_REWRITE.md` for Rob to run. Expected
   result: `.git` < 10 MB.

intent = learning atomistic potentials for inference (4–5 years stale — update or scrap).

### Findings that shape the plan
* Of 8 notebooks only **CNA** is real. `Changepoints`, `Kullback`, `MoI`, `RCut`,
  `Temperature_Average` are byte-identical copies of it (placeholders never written).
  `Ensemble_Average` is a stub with a stale import. `Emerald` is the Italian morphology script
  pasted into cells. → This is authorship, not repair.
* `legacy/Emerald` = morphology toolkit (CN/GCN, surface–core partition, shell peeling, surface
  area, volume, shell thickness, faceting ratio, solid angle, surface/bulk PDDFs). Unique parts:
  peeling, volume, thickness, faceting. → `Post_Process/Morphology.py`, vectorised.
* `legacy/CNA/main.py` = batch CNA-pattern classifier pipeline (dir of reference xyz → signatures
  → pattern dictionary → SVC). → `CNA/Classify.py` built on `FrameSignature` (no OVITO), feeding a
  cleaned `CNA/Model.py`.
* `Mass_Activity.py` cannot have run: `beta` (a function) is multiplied as a scalar (TypeError);
  histogram bins are data-ranged so `m/10 ≠ GCN`; `corrected_occ` flips the GCN axis; `r=1.28e-9 cm`
  is 0.128 Å; `density=True` then `/len(agcn)` double-normalises. Needs re-derivation with Rob.
