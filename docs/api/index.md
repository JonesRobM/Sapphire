# API overview

| Package | Purpose |
|---|---|
| `Sapphire.api` | `Config` + `run()` front door |
| `Sapphire.Process` | frame-by-frame driver |
| `Sapphire.Post_Process` | distances, kernels, adjacency, CNA inputs, morphology, mass activity, statistics |
| `Sapphire.CNA` | common-neighbour analysis and structure classification |
| `Sapphire.IO` | output tables and the `Reader` |
| `Sapphire.Graphing` | standard figures |
| `Sapphire.Potentials` | Gupta parameters/potential, ML calculators |
| `Sapphire.Utilities` | logging, error reporting, input cleaning, cluster builders |

::: Sapphire.api
